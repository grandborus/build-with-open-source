# Workshop Guide

## Welcome

This guide supports the **Build with Open Source** workshop. It gives a simple overview of the ideas and tools introduced during the session.

## What is Open Source?

Open source means that the code of a project is open for people to view, use, learn from, and improve.

Open source supports:
- learning,
- collaboration,
- sharing,
- and growth.

## What is Git?

Git is a tool that helps track changes in project files.

It helps you:
- save progress,
- understand what changed,
- and manage work more safely.

## What is GitHub?

GitHub is a platform for hosting repositories online. It helps people work together on projects.

With GitHub, people can:
- store repositories,
- share work,
- review changes,
- and collaborate more easily.

## What is a Repository?

A repository is the home of a project. It can contain:
- files,
- documentation,
- history,
- issues,
- and pull requests.

## What is VS Code?

VS Code is a code editor used for opening folders, editing files, writing code, and working with project tools.

## Basic Workflow

A simple workflow looks like this:
1. Clone a repository
2. Open it in VS Code
3. Make a change
4. Add the change
5. Commit the change
6. Push the change

## Practice Reminder

You do not need to do something big. A small and clear update is enough for practice.
