# Build with Open Source

A simple workshop repository for learning open source workflow with Git, GitHub, and VS Code.

## About this Repository

This repository is created for a workshop called **Build with Open Source**. It is designed to help participants understand the basic workflow of open source project work in a simple and practical way.

The main focus is on:
- understanding repositories,
- learning basic Git workflow,
- using GitHub for collaboration,
- working with files in VS Code,
- and exploring how project work can move toward deployment.

## Workshop Goals

By using this repository, participants should be able to:
- understand the role of a repository in project work,
- make simple updates to files,
- practice Git commands,
- understand commits and pushes,
- explore collaboration through GitHub,
- and see how project structure supports future deployment.

## Repository Structure

- `README.md` — introduction to the project
- `docs/guide.md` — a simple learning guide
- `src/index.html` — a basic project page
- `assets/style.css` — simple styling for the page

## Suggested Practice Tasks

### Beginner Tasks
- edit a section in the README
- improve wording in the guide
- update text in the HTML page

### Intermediate Tasks
- create a branch
- make a small improvement to the page
- open a pull request
- review another contribution

### Advanced Tasks
- support other participants
- suggest improvements to project structure
- help review pull requests
- guide others through workflow steps

## Basic Git Workflow

```bash
git clone <repository-url>
git status
git add .
git commit -m "My update"
git push
```
