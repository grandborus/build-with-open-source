# Contributing to Build with Open Source

Thank you for contributing to this workshop repository.

This repository is designed to help participants learn the basic workflow of open source project work in a simple and practical way.

## How to Contribute

You can contribute by making small and clear updates such as:
- improving the README
- updating the workshop guide
- fixing text or formatting
- improving the HTML page
- improving the styling

## Simple Contribution Workflow

1. Fork or clone the repository
2. Open the project in VS Code
3. Make a small change
4. Save your work
5. Add your changes using Git
6. Commit your changes with a clear message
7. Push your changes
8. Open a pull request if needed

## Basic Git Commands

```bash
git clone <repository-url>
git status
git add .
git commit -m "Describe your update"
git push
```

## Contribution Tips

- Start with a small change
- Keep your update clear and simple
- Use short and meaningful commit messages
- Read the file before editing it
- Ask questions if you are not sure

## Good Examples of Contributions

- fix a spelling mistake
- improve one sentence in the README
- update the workshop guide
- improve a heading on the page
- adjust simple styles in the CSS file

## During the Workshop

The goal is not to make big changes. The goal is to understand the workflow and practice the steps clearly.

## Be Respectful

Please be respectful when giving feedback, asking questions, or reviewing changes. Everyone is learning.

## Final Note

Small contributions matter. Start small, learn step by step, and keep building.
